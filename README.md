# StrataFlux

A system tray application for macOS and Windows that surfaces your Azure DevOps work items and GitHub pull requests in a unified, always-available view.

---

## Prerequisites

| Tool | Minimum version |
|------|----------------|
| Node.js | 18.0.0 |
| npm | 9.0.0 |

> **macOS only:** No additional build tools are required. Native modules ship pre-built via npm.  
> **Windows only:** Ensure the [Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) is installed (required by `keytar`).

---

## Quick start

```bash
# 1. Install dependencies (also generates placeholder tray icons)
npm install

# 2. Build main process + renderer
npm run build

# 3. Launch the app
npm start
```

The tray icon appears in the macOS menu bar or the Windows notification area. Click it to open the popup.

---

## Configuration

On first launch, click the tray icon → open the popup → click **Settings**.

| Field | Description |
|-------|-------------|
| ADO Organization URL | e.g. `https://dev.azure.com/myorg` |
| ADO Project | e.g. `MyProject` |
| ADO Personal Access Token | Scopes: `Work Items (Read)`, `Code (Read)` |
| GitHub Personal Access Token | Scopes: `repo:status`, `read:user`, `read:org` |
| Repositories | Optional. One `owner/repo` per line. Empty = all repos the token can access. |
| Poll interval | 5–15 minutes |

Click **Save & Connect** to persist credentials in the OS keychain (macOS Keychain / Windows Credential Manager). **Tokens are never written to disk.**

## Available scripts

| Script | Description |
|--------|-------------|
| `npm run build` | Compile TypeScript (main) and bundle React (renderer) |
| `npm run build:main` | Compile main process only |
| `npm run build:renderer` | Bundle renderer only |
| `npm start` | Launch the compiled app with Electron |
| `npm run dev` | Watch-mode: recompile main + serve renderer via Vite |
| `npm run typecheck` | Type-check both main and renderer without emitting |
| `npm run package` | Build + create distributable via electron-builder |

## Security notes

- ADO and GitHub tokens are stored exclusively in the OS credential store — never in `config.json` or any other file on disk.
- The renderer runs with `contextIsolation: true` and `nodeIntegration: false`. All external calls route through the main process via IPC.
- `shell.openExternal` validates that URLs use `https:` or `http:` only.
- Minimum recommended token scopes are listed in the Configuration table above.

---

## Known limitations (v1)

- Seen/unseen badge state resets on app restart.
- Linux is not officially supported (tray behaviour varies by desktop environment).
- Only a single ADO organization + project and a single GitHub identity are supported.
